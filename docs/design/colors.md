# Cores

Paleta de identidade (espelhada em `src/styles/variables.css`):

| Token | HEX | Uso |
|---|---|---|
| Green (primary) | `#104031` | Header, botão primário, texto forte |
| Gold (brand / accent) | `#a5894f` | Destaques, bordas, foco |
| Sand (secondary) | `#e0ccad` | Superfícies secundárias, hovers suaves |
| Paper (background) | `#f7f7f7` | Fundo da página |

Hover tipico do primary: `#1b5743`.

Gold funciona melhor como acento/borda do que como texto pequeno (contraste).
